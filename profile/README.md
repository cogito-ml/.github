# Cogito ML Systems

> **"Segmentation Fault" is just a state of mind.**

We build machine learning systems for people who want **control**, not magic.

## The Manifesto

1.  **Memory is yours.** If you want to leak it, that's your right.
2.  **Abstractions are expensive.** We sell zero-cost abstractions (and sometimes negative-cost ones).
3.  **Hardware is truth.** If it runs fast on the metal, it's good code.

## Core Projects

- [**cogito**](https://github.com/cogito-ml/cogito): The core C library. Pointers, arenas, and pain.
- [**cogito-serving**](https://github.com/cogito-ml/cogito-serving): Inference server that doesn't use HTTP because TCP is too slow.
- [**libcogito**](https://github.com/cogito-ml/libcogito): Bindings for languages lesser than C.
